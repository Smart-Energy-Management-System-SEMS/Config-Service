1. Nombre del microservicio:  
`Microservice-Analytics-Service` (Analytics Service)

2. Bounded Context al que pertenece:  
`Analytics` (dentro de SEMS)

3. Puerto local usado:  
`8004` (`PORT`, default en código y Docker)

4. Base URL local:  
`http://localhost:8004`

5. Base URL esperada para deploy:  
`https://<analytics-service-host>/api/v1/analytics`  
Referencia interna: Render sugiere `https://<tu-servicio>.onrender.com/api/v1/analytics/health`.

6. Endpoints principales expuestos al API Gateway:  
- `GET /api/v1/analytics/health`  
- `GET /api/v1/analytics/device-identifications/user/{user_id}`  
- `POST /api/v1/analytics/device-identifications`  
- `GET /api/v1/analytics/bill-predictions/user/{user_id}`  
- `POST /api/v1/analytics/bill-predictions`  
- `GET /api/v1/analytics/recommendations/user/{user_id}`  
- `POST /api/v1/analytics/recommendations`  
- `PATCH /api/v1/analytics/recommendations/{recommendation_id}/apply`  
- `GET /api/v1/analytics/anomalies/user/{user_id}`  
- `POST /api/v1/analytics/anomalies`  
- `PATCH /api/v1/analytics/anomalies/{anomaly_id}/resolve`  
- `GET /api/v1/analytics/consumption-rankings/user/{user_id}`  
- `POST /api/v1/analytics/consumption-rankings`

7. Prefijo base de rutas:  
`/api/v1/analytics`

8. Variables de entorno necesarias:  
- `PORT`  
- `MONGODB_URI`  
- `MONGODB_DATABASE`  
- `KAFKA_ENABLED`  
- `KAFKA_BOOTSTRAP_SERVERS`  
- `KAFKA_CONSUMER_GROUP`  
- `DEFAULT_TARIFF_PER_KWH`  
- `DEFAULT_CURRENCY`  
- `ANOMALY_THRESHOLD_PERCENTAGE`  
- `ALLOWED_ORIGINS`

9. Variables que son secretas y NO deben exponerse desde el Config Service:  
- `MONGODB_URI` (incluye credenciales)  
- Futuras credenciales Kafka si se agregan (`SASL_USERNAME`, `SASL_PASSWORD`, etc.)

10. Configuración Kafka usada:  
- bootstrap servers: `KAFKA_BOOTSTRAP_SERVERS` (local: `localhost:9092`, docker interno: `kafka:9092`)  
- security protocol: `PLAINTEXT` (en `docker-compose`, sin TLS)  
- SASL mechanism: no configurado  
- topics que produce:  
  - `analytics.bill_prediction.generated`  
  - `analytics.recommendation.generated`  
  - `analytics.anomaly.detected`  
  - `analytics.device_identified`  
  - `analytics.consumption_ranking.generated`  
- topics que consume:  
  - `energy.consumption.recorded`  
  - `device.registered`  
  - `device.updated`  
- consumer group: `analytics-service-group` (`KAFKA_CONSUMER_GROUP`)

11. Servicios externos que usa:  
- MongoDB Atlas (externo)  
- Kafka broker (local en dev vía Docker; externo en prod si se configura)

12. Base de datos usada:  
- motor: MongoDB (driver async Motor)  
- nombre de base de datos: `sems_analytics_db` (`MONGODB_DATABASE`)  
- variables de conexión: `MONGODB_URI`, `MONGODB_DATABASE`

13. Dependencias de otros microservicios:  
Por eventos consumidos, depende de servicios que publiquen:  
- `energy.consumption.recorded` (servicio de consumo/medición energética)  
- `device.registered` y `device.updated` (servicio de dispositivos)

14. Configuración que actualmente se repite y debería moverse al Config Service:  
- `PORT` por entorno  
- `API base path` (`/api/v1/analytics`) para gateway/routing  
- Bloque Kafka común (`enabled`, bootstrap, group, protocolos)  
- Convención de nombres de topics  
- Config CORS (`ALLOWED_ORIGINS`)  
- Parámetros de negocio configurables (`DEFAULT_TARIFF_PER_KWH`, `DEFAULT_CURRENCY`, `ANOMALY_THRESHOLD_PERCENTAGE`)  
- Base URL de healthcheck usada por keep-alive

15. Recomendación final de cómo debería registrarse este microservicio en el Config Service:  
Registrar una entrada tipo `analytics-service` con:  
- `serviceName`: `analytics-service`  
- `context`: `analytics`  
- `host/port` por entorno (`localhost:8004` en local; host deploy en prod)  
- `routePrefix`: `/api/v1/analytics`  
- `gatewayExposedEndpoints`: lista del punto 6  
- `kafka`: bootstrap/group/enabled + topics produce/consume  
- `database`: engine `mongodb`, db name `sems_analytics_db`  
- `nonSecretConfig`: tarifa/moneda/anomaly threshold/cors  
- `secretRefs`: referencias a secreto para `MONGODB_URI` (y futuros secretos Kafka), nunca en texto plano.
