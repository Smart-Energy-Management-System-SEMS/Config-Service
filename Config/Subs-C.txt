1. Nombre del microservicio:  
`microservice-subscriptions-service` (Subscriptions Service de SEMS)

2. Bounded Context al que pertenece:  
`Subscriptions` (gestión de planes y suscripciones; sin pagos directos)

3. Puerto local usado:  
`SERVER_PORT` (por defecto `8081`; en `.env.example` está `8082`; en deploy Render prioriza `PORT`)

4. Base URL local:  
`http://localhost:{PORT}`  
Usual según repo: `http://localhost:8081` (o `8082` si así se define)

5. Base URL esperada para deploy:  
No está fija en código. Se espera URL del proveedor (ej. Render):  
`https://<service-name>.onrender.com`

6. Endpoints principales expuestos al API Gateway:  
- `GET /api/v1/subscription-plans`  
- `GET /api/v1/subscription-plans/:planId`  
- `POST /api/v1/subscription-plans`  
- `PUT /api/v1/subscription-plans/:planId`  
- `PATCH /api/v1/subscription-plans/:planId/deactivate`  
- `GET /api/v1/subscriptions/:subscriptionId`  
- `GET /api/v1/subscriptions/users/:userId`  
- `POST /api/v1/subscriptions`  
- `PATCH /api/v1/subscriptions/:subscriptionId/cancel`  
- `PATCH /api/v1/subscriptions/:subscriptionId/change-plan`  
- `POST /api/v1/webhooks/stripe`  
- `GET /health` (healthcheck)

7. Prefijo base de rutas:  
`/api/v1` (más ` /health` fuera de ese prefijo)

8. Variables de entorno necesarias:  
- `PORT` (deploy) / `SERVER_PORT` (local)  
- `DATABASE_URL` (o alternativamente: `POSTGRES_HOST`, `POSTGRES_PORT`, `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_SSLMODE`, `POSTGRES_CHANNEL_BINDING`)  
- `STRIPE_SECRET_KEY`  
- `STRIPE_PUBLISHABLE_KEY`  
- `STRIPE_WEBHOOK_SECRET`  
- `STRIPE_CURRENCY`  
- `STRIPE_PRICE_FREE`  
- `STRIPE_PRICE_PLUS`  
- `STRIPE_PRICE_PRO`  
- `KAFKA_ENABLED`  
- `KAFKA_BOOTSTRAP_SERVERS`  
- `KAFKA_BROKERS`  
- `KAFKA_CLIENT_ID`  
- `KAFKA_USERNAME`  
- `KAFKA_PASSWORD`  
- `KAFKA_SECURITY_PROTOCOL`  
- `KAFKA_SASL_MECHANISM`  
- `KAFKA_CA_CERT` / `KAFKA_CA_CERT_PATH` (opcionales)

9. Variables que son secretas y NO deben exponerse desde el Config Service:  
- `DATABASE_URL`  
- `POSTGRES_PASSWORD`  
- `STRIPE_SECRET_KEY`  
- `STRIPE_WEBHOOK_SECRET`  
- `KAFKA_PASSWORD`  
- `KAFKA_CA_CERT` (si contiene material sensible)

10. Configuración Kafka usada:  
- bootstrap servers: `KAFKA_BOOTSTRAP_SERVERS` (fallback `KAFKA_BROKERS`)  
- security protocol: `KAFKA_SECURITY_PROTOCOL` (`SASL_SSL` en Aiven, `PLAINTEXT` local opcional)  
- SASL mechanism: `KAFKA_SASL_MECHANISM` (`SCRAM-SHA-256` recomendado en Aiven)  
- topics que produce:  
  - `SubscriptionCreated`  
  - `SubscriptionCancelled`  
  - `SubscriptionPlanChanged`  
  - `SubscriptionExpired`  
  - `SubscriptionUpdated`  
- topics que consume: no se encontró consumidor Kafka en este servicio  
- consumer group: no aplica (sin consumer)

11. Servicios externos que usa:  
- Stripe (API + Webhooks)  
- Kafka broker (Aiven sugerido en documentación)  
- PostgreSQL (Neon mencionado en README)

12. Base de datos usada:  
- motor: PostgreSQL (con GORM)  
- nombre de base de datos: valor de `POSTGRES_DB` o el incluido en `DATABASE_URL`  
- variables de conexión: `DATABASE_URL` o `POSTGRES_HOST`, `POSTGRES_PORT`, `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_SSLMODE`, `POSTGRES_CHANNEL_BINDING`

13. Dependencias de otros microservicios:  
No se observan llamadas directas HTTP/gRPC a otros microservicios.  
Dependencia indirecta por eventos Kafka e integración con IAM vía `user_id` (solo referencia de dato).

14. Configuración que actualmente se repite y debería moverse al Config Service:  
- Puerto/host base (`PORT`/`SERVER_PORT`)  
- Prefijo de API y metadatos de rutas (`/api/v1`)  
- Config común Kafka (`enabled`, brokers, protocol, mechanism, client id)  
- Config común DB no sensible (`host`, `port`, `db`, `sslmode`, `channelBinding`)  
- Identificadores funcionales no secretos (`STRIPE_PRICE_FREE/PLUS/PRO`, `STRIPE_CURRENCY`)  
- Health endpoint estándar (`/health`)

15. Recomendación final de cómo debería registrarse este microservicio en el Config Service:  
Registrar un bloque `subscriptions-service` con separación clara entre `public-config` y `secrets`:

- `service.name`: `subscriptions-service`  
- `service.context`: `subscriptions`  
- `service.basePath`: `/api/v1`  
- `service.healthPath`: `/health`  
- `service.port`: `8081` (override por entorno)  
- `apiGateway.exposedRoutes`: lista de endpoints anteriores  
- `kafka`: brokers/protocol/mechanism/clientId + catálogo de topics producidos  
- `database`: motor y parámetros no secretos  
- `integrations.stripe`: currency + price IDs (no claves secretas)  
- `secretsRef`: referencias a vault/secret-manager para credenciales DB, Stripe y Kafka.
