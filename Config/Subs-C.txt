1. Nombre del microservicio:
`subscriptions-service`

2. Bounded Context al que pertenece:
`Subscriptions` (planes y suscripciones)

3. Puerto local usado:
`18083` (`SERVER_PORT`; prioridad `PORT` > `SERVER_PORT` > Config Service > fallback `8080`)

4. Base URL local:
`http://localhost:18083`

5. Base URL esperada para deploy:
`https://<subscriptions-service-host>`

6. Endpoints principales expuestos al API Gateway:
- `GET /api/v1/subscription-plans`
- `GET /api/v1/subscription-plans/:planId`
- `POST /api/v1/subscription-plans`
- `PUT /api/v1/subscription-plans/:planId`
- `PATCH /api/v1/subscription-plans/:planId/deactivate`
- `GET /api/v1/subscriptions/:subscriptionId`
- `GET /api/v1/subscriptions/users/:userId`
- `POST /api/v1/subscriptions`
- `PATCH /api/v1/subscriptions/:subscriptionId/cancel`
- `PATCH /api/v1/subscriptions/:subscriptionId/change-plan`
- `POST /api/v1/webhooks/stripe`

7. Prefijo base de rutas:
`/api/v1`

8. Variables de entorno necesarias:
- `PORT`
- `SERVER_PORT`
- `DATABASE_URL`
- `STRIPE_SECRET_KEY`
- `STRIPE_PUBLISHABLE_KEY`
- `STRIPE_WEBHOOK_SECRET`
- `STRIPE_CURRENCY`
- `STRIPE_PRICE_FREE`
- `STRIPE_PRICE_PLUS`
- `STRIPE_PRICE_PRO`
- `KAFKA_ENABLED`
- `KAFKA_BOOTSTRAP_SERVERS`
- `KAFKA_BROKERS`
- `KAFKA_CLIENT_ID`
- `KAFKA_USERNAME`
- `KAFKA_PASSWORD`
- `KAFKA_SECURITY_PROTOCOL`
- `KAFKA_SASL_MECHANISM`

9. Variables que son secretas y NO deben exponerse desde el Config Service:
- `DATABASE_URL`
- `POSTGRES_PASSWORD`
- `STRIPE_SECRET_KEY`
- `STRIPE_WEBHOOK_SECRET`
- `KAFKA_PASSWORD`
- `KAFKA_CA_CERT`

10. Configuracion Kafka usada:
- bootstrap servers: `KAFKA_BOOTSTRAP_SERVERS` (fallback `KAFKA_BROKERS`)
- topics que produce:
  - `SubscriptionCreated`
  - `SubscriptionCancelled`
  - `SubscriptionPlanChanged`
  - `SubscriptionExpired`
  - `SubscriptionUpdated`
- topics que consume: ninguno confirmado

11. Servicios externos que usa:
- Stripe
- Kafka broker
- PostgreSQL

12. Base de datos usada:
- motor: PostgreSQL
- variables de conexion: `DATABASE_URL` o variables `POSTGRES_*`

13. Dependencias de otros microservicios:
- No se observan llamadas HTTP directas.
- Integracion indirecta por eventos Kafka y referencias `user_id`.
