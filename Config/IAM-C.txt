1. Nombre del microservicio:
`iam-service` (Spring Boot)

2. Bounded Context al que pertenece:
`IAM` (Identity and Access Management)

3. Puerto local usado:
`8082` (`SERVER_PORT`; fallback Spring `8080`)

4. Base URL local:
`http://localhost:8082`

5. Base URL esperada para deploy:
`https://<iam-service-host>`

6. Endpoints principales expuestos al API Gateway:
- `POST /api/v1/auth/register`
- `POST /api/v1/auth/login`
- `POST /api/v1/auth/google`
- `GET /api/v1/auth/google/callback`
- `GET /api/v1/auth/google/url`
- `GET /api/v1/users/me`
- `GET /api/v1/users`
- `POST /api/v1/users/{userId}/roles`
- `GET /health`
- `GET /actuator/health`

7. Prefijo base de rutas:
`/api/v1`
Subprefijos: `/api/v1/auth`, `/api/v1/users`

8. Variables de entorno necesarias:
- `SERVER_PORT`
- `IAM_PORT`
- `DB_URL`
- `DB_USERNAME`
- `DB_PASSWORD`
- `JWT_SECRET`
- `JWT_EXPIRATION_MINUTES`
- `KAFKA_ENABLED`
- `KAFKA_BOOTSTRAP_SERVERS`
- `KAFKA_BROKERS`
- `KAFKA_SECURITY_PROTOCOL`
- `KAFKA_SASL_MECHANISM`
- `KAFKA_CONSUMER_GROUP_ID`
- `GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`
- `GOOGLE_REDIRECT_URI`
- `GOOGLE_SCOPES`

9. Variables que son secretas y NO deben exponerse desde el Config Service:
- `DB_PASSWORD`
- `JWT_SECRET`
- `KAFKA_PASSWORD`
- `KAFKA_USERNAME`
- `KAFKA_SSL_CA_CERT`
- `KAFKA_SASL_JAAS_CONFIG`
- `GOOGLE_CLIENT_SECRET`

10. Configuracion Kafka usada:
- bootstrap servers: `KAFKA_BOOTSTRAP_SERVERS` (fallback `KAFKA_BROKERS`)
- security protocol: `KAFKA_SECURITY_PROTOCOL`
- SASL mechanism: `KAFKA_SASL_MECHANISM`
- topics que produce:
  - `iam.user.registered`
  - `iam.user.logged-in`
  - `iam.role.assigned`
- topics que consume:
  - `iam.role-assignment.requested`
- consumer group: `KAFKA_CONSUMER_GROUP_ID` (default `iam-service`)

11. Servicios externos que usa:
- PostgreSQL
- Kafka broker/cluster
- Google OAuth 2.0

12. Base de datos usada:
- motor: PostgreSQL
- variables de conexion: `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`

13. Dependencias de otros microservicios:
- No se observan llamadas HTTP salientes directas.
- Dependencia asincrona por eventos Kafka: consume `iam.role-assignment.requested`.
