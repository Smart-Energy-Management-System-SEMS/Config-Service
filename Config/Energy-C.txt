1. Nombre del microservicio:
`energy-monitoring-service`

2. Bounded Context al que pertenece:
`Monitoring` (Energy Monitoring)

3. Puerto local usado:
`8001` (`APP_PORT=8001`; fallback `8080`)

4. Base URL local:
`http://localhost:8001`

5. Base URL esperada para deploy:
`https://<energy-monitoring-service-host>`

6. Endpoints principales expuestos al API Gateway:
- `POST /api/v1/energy-readings`
- `GET /api/v1/energy-readings/user/{user_id}`
- `GET /api/v1/energy-readings/device/{device_id}`
- `GET /api/v1/energy-readings/range`
- `GET /api/v1/energy-readings/meter/{meter_id}/latest`
- `GET /api/v1/energy-readings/{reading_id}`
- `POST /api/v1/device-consumptions`
- `GET /api/v1/device-consumptions/user/{user_id}`
- `GET /api/v1/device-consumptions/user/{user_id}/top`
- `GET /api/v1/device-consumptions/{consumption_id}`
- `POST /api/v1/consumption-alerts`
- `GET /api/v1/consumption-alerts/user/{user_id}`
- `GET /api/v1/consumption-alerts/user/{user_id}/unread`
- `PATCH /api/v1/consumption-alerts/{alert_id}/read`
- `PATCH /api/v1/consumption-alerts/{alert_id}/resolve`
- `GET /api/v1/consumption-alerts/{alert_id}`
- `POST /api/v1/energy-meters`
- `GET /api/v1/energy-meters/user/{user_id}`
- `PATCH /api/v1/energy-meters/{meter_id}/deactivate`
- `GET /api/v1/energy-meters/{meter_id}`

7. Prefijo base de rutas:
`/api/v1`

8. Variables de entorno necesarias:
- `MONGODB_URL`
- `MONGODB_DATABASE`
- `KAFKA_BOOTSTRAP_SERVERS`
- `KAFKA_GROUP_ID`
- `KAFKA_TOPIC_READING_INGEST`
- `KAFKA_TOPIC_ANOMALY_DETECTED`
- `KAFKA_TOPIC_ALERT_CREATED`
- `KAFKA_TOPIC_READING_PROCESSED`
- `APP_HOST`
- `APP_PORT`
- `APP_ENV`

9. Variables que son secretas y NO deben exponerse desde el Config Service:
- `MONGODB_URL`

10. Configuracion Kafka usada:
- bootstrap servers: `KAFKA_BOOTSTRAP_SERVERS`
- topics que produce:
  - `monitoring.alert.created`
  - `monitoring.reading.processed`
- topics que consume:
  - `monitoring.reading.ingest`
  - `analytics.anomaly.detected`
- consumer group: `energy-monitoring-group`

11. Servicios externos que usa:
- Kafka broker
- MongoDB

12. Base de datos usada:
- motor: MongoDB
- variables de conexion: `MONGODB_URL`, `MONGODB_DATABASE`

13. Dependencias de otros microservicios:
- Dependencia asincrona por eventos de Analytics Service.
- No hay llamadas HTTP directas confirmadas.
